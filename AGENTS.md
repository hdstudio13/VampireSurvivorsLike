# Codex Project Instructions

Before starting any task in this repository:

1. Read `docs/AI_CONTEXT.md`.
2. Use `docs/ARCHITECTURE.md` as the routing index and open only the smallest relevant branch file under `docs/architecture/`, `docs/features/`, `docs/systems/`, or `docs/workflows/`.
3. Read `docs/DECISIONS.md` before changing architecture, conventions, workflows, or cross-cutting behavior.
4. Read `docs/standards/code-quality.md` before implementing or reviewing first-party code.
5. Read `docs/CHANGELOG.md` before summarizing recent project changes or adding new change notes.
6. Inspect source files only after using the docs to narrow the search.
7. When making meaningful changes, update the relevant documentation branch in `docs/` as part of the same task.

Keep documentation concise, current, tree-based, and optimized for future Codex context.
Keep first-party code enterprise-grade: maintainable, extendable, SOLID, aligned with common patterns, and documented where intent is non-obvious.
